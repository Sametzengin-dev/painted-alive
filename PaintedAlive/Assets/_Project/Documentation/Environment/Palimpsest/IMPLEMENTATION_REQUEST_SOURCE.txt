IMPORTANT GAMEPLAY RULE:

When a Figure moves behind the canvas,
the Painter must NOT receive exact positional information.

But the Figure is NOT completely invisible.

Painter receives coarse/uncertain information such as:

- approximate canvas deformation
- dust/pigment displacement
- vague trace
- subtle front-canvas bulge

Each trace helper has approximately:

uncertainty_radius_m = 3

according to the handoff.

Do NOT expose the exact network transform of the Figure through this visual system.

The Figure should be able to mislead Painter by changing routes behind the canvas.

Preserve player camera and traversal normally.

Do not use teleportation to move between front/back.
